# LIFT outreach anti-slop list

Version: lifty-anti-slop.v12

These are the words and phrases LIFT avoids in LinkedIn and email copy. The
list below is the one LIFT's composer reads and checks drafts against. It is
served live, so it can change between sessions.

Avoid them when you draft. Match case-insensitively and avoid close variants
that keep the same tell ("Quick question for you", "just curious", "mind if
we hop on a call"). Global applies to both channels; Email and LinkedIn apply
only to that channel.

They are recommendations, not blocks. When a saved template contains one, the
campaign response lists it in `writing_recommendations`. Point it out to the
founder with a rewrite. If the founder wants to keep the wording, keep it.

This is a writing ban, not a claim about response rates.
