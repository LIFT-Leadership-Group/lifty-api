# Lifty operation catalog

Read whoami and next_step when starting or resuming. next_step names the stage behind the current step (`context_task`) and the stages its actions lead to (`related_contexts`): when the founder asks for something else at that step, such as calibrating the sample, read the matching related stage first. Context operations below are generated from the server catalog, which owns methods, routes, schemas and CLI nouns. Choose the resource that owns the requested fact. Business setup, the sample, weekly research, researched leads, external accounts and campaign activation have independent state and authorization.
