# Workspace summary

Read summary for the selected workspace and the requested resource before asking for saved information. Business is the typed commercial profile; setup reports profile, targeting, criteria and voice versions, while setup_status is the immutable setup receipt. Unavailable means retry, not missing setup.

Use next_step to resume from resource state, not a local done flag. Existing resources configured outside setup are valid. Leads-only customers can keep reviewing results without senders, warmup, campaigns or a CRM; offer optional work only when relevant to their request. Preparation, connection, calibration and payment never activate outreach.

Zero legacy templates is normal for a generated campaign: read its compose mode and preparation state before claiming it is unconfigured.
